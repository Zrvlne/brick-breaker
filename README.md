# Ghost Brick Breaker

A neon ghost-themed brick breaker game made with **Godot 4**. Move the paddle, bounce the flaming soccer ball, and clear every brick to move on to the next level.

**Play it on itch.io:** [https://zrvlne.itch.io/ghost-breaker]

## Features and Instructions

The bricks are randomly generated, and you have to break them with a ball. You can move the paddle using left arrow and the right arrow and then the paddle moves!

Click **START** on the menu to begin.
